# Decompiled code (read-only reference)

- These files are tool output: never edit them. Record names you give to symbols in
  `notes/renames.json`, so they survive a re-decompilation after a game update.
- Search before opening big files (the code index, `rg -n`, Read with offset/limit).
- Ghidra pseudo-C names (FUN_/DAT_/LAB_) are placeholders: confirm meaning from xrefs, strings and
  runtime before stating it as fact.
- Cite evidence as `decomp/<path>:<line>` or an index id.
